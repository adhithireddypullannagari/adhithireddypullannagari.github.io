# Adhithi Reddy Pullannagari — Portfolio

Static portfolio website for GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub repository named `adhithireddypullannagari.github.io`.
2. Upload all files in this folder, including the `certificates` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your website will be available at `https://adhithireddypullannagari.github.io/` after GitHub Pages finishes deploying.
